{% load static %} {% comment %} The numeric face: Spline Sans Mono, applied to DIGITS ONLY. `CPNum` is declared with a unicode-range covering 0-9 and the characters that sit inside figures (. , - + % ₹ /), so a font stack that starts with CPNum (`--rz-num` in base.html) draws the digits in the monospace and falls through to the next font for every letter. Every digit is the same width, so columns of figures line up. Served from core/static/fonts, never a CDN: the panel must work with no internet.
